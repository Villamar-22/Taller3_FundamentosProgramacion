# Taller 3 – Fundamentos de Programación

## Descripción
Este repositorio contiene la solución del Taller 3 de la asignatura
Fundamentos de Programación, desarrollado en Java.

## Programas incluidos

### 1. Sistema de Cálculo Nutricional Comida Consumida
Permite ingresar ingredientes y calcular información nutricional básica
según los datos ingresados por el usuario.

Archivo: `Nutricion.java`

### 2. Lista de Películas por Año de Lanzamiento
Permite registrar películas según su género y mostrar la información
ingresada por consola.

Archivo: `Peliculas.java`

## Tecnologías utilizadas
- Java
- Visual Studio Code
- Git y GitHub
